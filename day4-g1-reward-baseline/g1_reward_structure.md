# G1 보상 구조 분석

> 대상: Isaac Lab G1 평지 보행 과제(`Isaac-Velocity-Flat-G1-v0`)의 보상 구조

---

## 1. 보상의 세 그룹

```text
┌────────────────────┐  ┌────────────────────┐  ┌────────────────────┐
│  ① 명령대로 걸어라  │  │ ② 얌전하게 움직여라 │  │  ③ 자세 바르게 해라 │
│     잘하면 + 점수   │  │     어기면 − 점수   │  │     어기면 − 점수   │
├────────────────────┤  ├────────────────────┤  ├────────────────────┤
│ track_lin_vel_xy   │  │ action_rate_l2     │  │ flat_orientation_l2│
│ track_ang_vel_z    │  │ dof_torques_l2     │  │ joint_deviation_*  │
│ feet_air_time      │  │ dof_acc_l2         │  │ lin_vel_z_l2       │
│                    │  │ feet_slide         │  │ termination_penalty│
└────────────────────┘  └────────────────────┘  └────────────────────┘
       "무엇을"                       "어떻게"
```

### ① 명령대로 걸어라 (상점 +)

| 이름 | 쉬운 뜻 |
|---|---|
| `track_lin_vel_xy_exp` | "앞으로 0.5m/s로 가" 같은 **이동 명령**을 잘 따르면 상 |
| `track_ang_vel_z_exp` | "왼쪽으로 돌아" 같은 **회전 명령**을 잘 따르면 상 |
| `feet_air_time` | **발을 공중에 적당히 들었다 놓으면** 상 (= 진짜 걸음걸이) |

→ 로봇의 **진짜 목표**. Cartpole의 `alive(+1)`과 같은 역할.

### ② 얌전하게 움직여라 (벌점 −)

| 이름 | 쉬운 뜻 |
|---|---|
| `action_rate_l2` | 행동이 **갑자기 확 바뀌면** 벌점 → 떨림 방지 |
| `dof_torques_l2` | 관절에 **힘을 너무 세게** 쓰면 벌점 → 모터 보호 |
| `dof_acc_l2` | 관절이 **급가속**하면 벌점 |
| `feet_slide` | 땅 위에서 **발이 미끄러지면** 벌점 |

### ③ 자세 바르게 해라 (벌점 −)

| 이름 | 쉬운 뜻 |
|---|---|
| `flat_orientation_l2` | 몸통이 **기울어지면** 벌점 |
| `joint_deviation_*` | 팔·엉덩이 등이 **기본 자세에서 너무 벗어나면** 벌점 |
| `lin_vel_z_l2` | 몸이 **위아래로 출렁이면** 벌점 |
| `termination_penalty` | **넘어지면** 큰 벌점 |

### 용어 메모

- `_l2`: 값을 **제곱**해서 벌점을 준다. 조금 어긋나면 벌점이 작고, 많이 어긋나면 확 커진다.
- `_exp`: 명령과 실제 값이 가까울수록 1에 가까운 상점을 준다.

### 상점과 벌점의 역할

> **상점(+)은 로봇이 "무엇을" 할지, 벌점(−)은 "어떻게" 할지를 정한다.**

- 상점만 있으면 → 목표는 달성하지만 덜덜 떨거나 이상한 자세로 걸을 수 있다
- 벌점이 그걸 **사람이 보기에 자연스럽고, 실제 로봇이 버틸 수 있는 움직임**으로 다듬는다

## 2. 보상 해킹 (reward hacking)

> 사람이 원한 것과 다르게, **점수만 잘 받는 꼼수**를 로봇이 배우는 현상

상점 없이 벌점만 있는 점수표라면, 로봇은 가장 덜 마이너스가 되는 쪽으로 학습한다. 그 결과는 정상 보행이 아니다. 숫자로 따라가 보면:

```text
[상황] 상점은 없고, 벌점만 있는 점수표

선택지 A: 열심히 걷는다
  → 다리를 움직이니까 힘 벌점, 가속 벌점, 흔들림 벌점...
  → 총점: -50점

선택지 B: 그냥 가만히 서 있는다
  → 아무것도 안 하니까 벌점이 거의 없음
  → 총점: -2점

로봇의 선택: B (가만히 서 있기)
```

로봇 입장에서는 **"아무것도 안 하는 게 가장 덜 혼나는 방법"**이다. 걸으라는 상점이 없으니 걸을 이유가 없다.

넘어짐 벌점이 작으면 더 이상한 일이 생긴다:

```text
선택지 C: 시작하자마자 일부러 넘어진다
  → 에피소드가 바로 끝나서 벌점이 더 쌓이지 않음
  → 총점: -1점  ← 이게 최고점!
```

이걸 막으려면 점수표에 반드시 두 가지가 함께 있어야 한다.

| 필요한 것 | 역할 |
|---|---|
| **상점** | "걸어야 할 이유"를 준다 |
| **넘어짐 큰 벌점** | "일부러 에피소드를 끝내는 꼼수"를 막는다 |

Cartpole에 `alive +1`과 `terminating -2`가 **같이** 있었던 것도 바로 이 이유다.

## 3. 정리

G1 휴머노이드의 보상은 크게 3그룹으로 나뉜다.

1. **명령대로 걸어라 (상점)**: 이동 명령, 회전 명령, 걸을 때 발의 체공시간
2. **얌전하게 움직여라 (벌점)**: 행동 급변, 과도한 힘(모터 보호), 관절 급가속, 발 미끄러짐
3. **자세 바르게 해라 (벌점)**: 몸통 기울기, 기본자세 이탈, 위아래 출렁임, 넘어짐(큰 벌점)

상점은 로봇이 "무엇을" 할지, 벌점은 "어떻게" 할지를 정한다.
상점 없이 벌점만 있으면 로봇은 가만히 서 있거나 일부러 넘어지는 쪽이 점수가 더 높다고 배울 수 있다(보상 해킹). 그래서 두 종류가 함께 필요하다.
